# Proposed new citation subjects: additives with no rule yet (Oct 23, 2026)

**Status: PENDING OWNER APPROVAL. Nothing here is in the app.** Report, don't rule: these
additives grade *Questionable* today only because no cited source covers them.

Why it matters: in a 314-product US probe, 195 products graded Questionable, mostly because of
these codes ("In probe" = products in the probe containing it).

**20 codes are listed Halal with no condition** by Source A; the rest are conditional.

## Source A (candidate)

- **Halal Authority India, "FOOD INGREDIENT NUMBERS: (E-numbers)"**: 16-page table with a Halal Status column.
  <https://www.halalauthorityindia.com/pages/ecodes/6198ecodes.pdf> (fetched 2026-10-23, sha256 3b2596051d626c9b…).
- **Publisher identity unverified**: not in the NABCB / HAK accreditation results I found; the homepage
  blocks automated reads. Wording ("In USA it is always from non dairy source") suggests it reproduces an
  IFANCA-style table. Tier 1 only if you recognise the body; otherwise tier 3 and a second source is needed.

## Source B (corroborating, tier 1, a certifier)

- **The Halaal Department (Malawi)**, per-code pages, e.g. <https://halaalmalawi.org/halaal-e-numbers/e101-riboflavin/>:
  E101 "Status Halaal … Source: Microbiological; Synthetic"; E102 and E110 "Status Halaal … Source: Synthetic";
  E440(a) "Status Halaal … Check that source is not from cider making". Covers only 23 codes.

## What approving means

1. Each approved code gets a seeded GradeMatrix row for all four standards: draft Halal for
   "no condition" codes; conditional codes stay Questionable (widely accepted) until origin is known.
2. Candidates go through the normal pipeline (docs/citations/candidates/, then CitationCommitter).
   Section 8: lenient and high-traffic cells need two independent sources. Source B covers only E101, E102,
   E110 and E440, so most codes need a second source before they can clear.
3. Disagreements to rule on: E101 riboflavin (A: Mushbooh unless plant; B: Halaal, microbial/synthetic)
   and E440 pectin (A: Halal; B: Halaal, but check it is not from cider making).
