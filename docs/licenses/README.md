# Bundled font licenses

The repo redistributes the font binaries in `Haliable/Resources/Fonts`, so the
licence text has to travel with them (SIL OFL 1.1 §2). In-app credit lives on the
Acknowledgements screen (`Haliable/Views/Settings/AcknowledgementsView.swift`).

| Font | Licence | Used for |
|---|---|---|
| Spectral (Light/Regular/Medium) | SIL OFL 1.1 — `OFL-Spectral.txt` | Display serif: titles, card headers, "Ha" |
| Instrument Serif Italic | SIL OFL 1.1 — `OFL-InstrumentSerif.txt` | Editorial italic accent: "liable", taglines |
| Playfair Display, Playfair Display Italic | SIL OFL 1.1 | legacy / v1 screens |
| Nunito Italic | SIL OFL 1.1 | wordmark variant |
| Yellowtail | Apache License 2.0 | script accent |

Replaced Oct 13, 2026: Romie Trial and Ernest Trial (Margot Lévêque) were
**evaluation-only** licences and could not legally ship. Do not reintroduce them.
